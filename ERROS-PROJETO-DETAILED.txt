# Lista Exaustiva de TODOS os Erros no Código - TodoList Fullstack

Documento com **CADA erro identificado** nos códigos backend/frontend/DB/Docker. Explicação detalhada: arquivo, linha, problema, impacto, correção sugerida.

## ERROS BACKEND (Node.js/Express/MySQL)

1. **server.js - Linha com log:**
   ```
   console.log(`Server ruuning ${PORT}...`);
   ```
   - **Erro**: Typo "ruuning" -> "running".
   - **Impacto**: Log feio, não quebra.
   - **Fix**: `Server running on port ${PORT}`.

2. **router.js - Duas referências:**
   ```
   validateFieldtTitle
   ```
   - **Erro**: Typo "FieldtTitle" -> "FieldTitle".
   - **Impacto**: OK se middleware nomeado assim, mas inconsistente.
   - **Fix**: Renomeie middleware ou corrigir import/use.

3. **middlewares/tasksMiddleware.js - Nome função:**
   ```
   const validateFieldtTitle = ...
   ```
   - **Erro**: Typo "FieldtTitle".
   - **Impacto**: Funciona, mas código feio.
   - **Fix**: `validateFieldTitle`.

4. **middlewares/tasksMiddleware.js - Mensagem erro status:**
   ```
   res.status(400).json({message : 'The title cannot be empty'});  // Em validateFieldStatus!
   ```
   - **Erro**: Msg diz "title" mas é para status.
   - **Impacto**: Confuso para user.
   - **Fix**: `'The status cannot be empty'`.

5. **controllers/tasksController.js - Nome export:**
   ```
   updatedTask
   ```
   - **Erro**: "updated" -> "updateTask" padrão.
   - **Impacto**: Funciona, inconsistente.
   - **Fix**: Renomeie função/export.

6. **models/tasksModel.js - Response createTask:**
   ```
   create_at: new Date().toISOString()
   ```
   - **Erro**: Typo "create_at" -> "created_at"; usa JS Date não BD TIMESTAMP.
   - **Impacto**: Frontend recebe campo errado/data inconsistente.
   - **Fix**: `created_at: new Date().toISOString()` ou SELECT após INSERT.

7. **models/tasksModel.js - updateTask:**
   ```
   const {title, status} = task;  // Assume ambos presentes
   ```
   - **Erro**: Não lida opcionais (ex só status).
   - **Impacto**: Crash se campo missing.
   - **Fix**: Dynamic query ou defaults.

8. **src/app.js:**
   ```
   // Sem app.use(cors())
   ```
   - **Erro**: cors instalado mas não usado.
   - **Impacto**: **CORS bloqueia fetch frontend** (5173 != 3333).
   - **Fix**: `const cors = require('cors'); app.use(cors());`.

9. **Geral Backend:**
   - Sem try/catch global -> unhandled errors crash server.
   - Sem validação enum status no model.

## ERROS FRONTEND (React/Vite)

1. **src/App.jsx - API_URL:**
   ```
   const API_URL = "";
   fetch(`${API_URL}/tasks`);  // -> "/tasks" ? Não, falha!
   ```
   - **Erro**: Com "" + proxy Vite (/tasks relativo), mas `${''}/tasks` = "/tasks" OK? Wait, fetch("/tasks") esperado para proxy.
   - **Test**: Se não salva, ver console CORS ou 404.
   - **Impacto**: **Não salva tarefas** - fetch falha silenciosamente (só console).
   - **Fix**: `fetch('/tasks')` direto (proxy pega).

2. **src/App.jsx - Sem feedback erro:**
   - console.error só.
   - **Impacto**: User não vê por quê falha.
   - **Fix**: State error + toast/alert.

3. **TaskRow.jsx:**
   ```
   alert("O título não pode estar vazio!");
   ```
   - **Erro**: alert() feio.
   - **Fix**: Modal/toast.

4. **Geral Frontend:**
   - Sem React Hook Form/validação input.
   - Estado local - OK para small app.

## ERROS DOCKER/CONFIG

1. **docker-compose.yml:**
   - Backend ports: `"${PORT}:3333"` - PORT deve ser no .env (ex 3333).
   - Frontend env `VITE_API_URL: http://backend:3333` - OK Docker.
   - **Mas dev local**: Vite proxy usa localhost:3333.

2. **.env faltando?** MYSQL vars para backend/DB.

## PROBLEMAS ESPECÍFICOS REPORTADOS

1. **"Não consigo salvar tarefas"**:
   - **Causa principal**: CORS (app.js sem cors()) + API_URL "" pode não proxy.
   - **Debug**: Abra DevTools Network - veja fetch erro  (CORS/404).
   - **Fix rápido**: Adicione cors() em app.js; use fetch('/tasks').

2. **"Barra lateral não aparece ao criar nova tarefa"**:
   - **Causa**: Sidebar.js em tabs mas **arquivo não existe** no FS!
   - App.jsx é só table + form - sem sidebar.
   - **Impacto**: UI básica sem sidebar.
   - **Fix**: Implemente Sidebar component + conditional render em App (ex após addTask).

## PASSOS DEBUG/FIX

1. Backend: `cd backend && npm i && npm run dev` - ver log "running".
2. Frontend: `cd frontend && npm run dev` - http://localhost:5173.
3. DevTools Console/Network - erros fetch?
4. Adicione em backend/app.js: `app.use(require('cors')());`
5. App.jsx: Mude para `fetch('/tasks')` (remove API_URL).
6. Docker: `docker-compose up --build` - ver logs.

**Cada erro listado acima quebra ou degrada a app**. Priorize CORS + API_URL + sidebar missing.
