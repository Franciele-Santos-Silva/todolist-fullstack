# DOCUMENTAÇÃO COMPLETA DO PROJETO TODOLIST FULLSTACK

## VISÃO GERAL
Este é um projeto **TodoList Fullstack** completo e containerizado, desenvolvido para gerenciamento de tarefas. Possui:
- **Frontend**: Interface React moderna com Vite
- **Backend**: API REST Node.js/Express com MySQL
- **Banco de Dados**: MySQL com script de inicialização
- **Docker**: Containerização completa com docker-compose

O projeto implementa operações CRUD completas para tarefas, com validação, status (pendente/em andamento/concluída) e interface intuitiva.

## FUNCIONALIDADES

### Backend API (http://localhost:3333)
| Método | Endpoint     | Descrição                  |
|--------|--------------|----------------------------|
| GET    | /tasks       | Listar todas tarefas       |
| POST   | /tasks       | Criar tarefa `{title}`     |
| PUT    | /tasks/:id   | Atualizar `{title, status}`|
| DELETE | /tasks/:id   | Deletar tarefa             |

**Status válidos**: `pendente`, `em andamento`, `concluida`

**Validações**: Title obrigatório, status válido.

### Frontend
- Lista de tarefas com filtros por status
- CRUD completo (Criar, Ler, Atualizar, Deletar)
- Detalhes de tarefa individual
- Sidebar de navegação
- Context API para estado global
- Hook customizado `useTasks`
- Design responsivo

## SETUP E EXECUÇÃO

### 1. Pré-requisitos
```
Docker + Docker Compose
Node.js 18+ (opcional, para dev local)
MySQL client (opcional, para debug)
```

### 2. Configuração (.env no backend)
```
MYSQL_HOST=mysql
MYSQL_USER=root
MYSQL_PASSWORD=root
MYSQL_DB=todolist
MYSQL_PORT=3306
PORT=3333
```

### 3. Executar com Docker (RECOMENDADO)
```bash
# Build e up
docker-compose up --build

# URLs:
# Backend API: http://localhost:3333/tasks
# Frontend:   http://localhost:5173 (Vite dev) ou 80 (nginx prod)
```

### 4. Desenvolvimento Local (sem Docker)
```bash
# Backend
cd backend
npm install
npm run dev

# Frontend (terminal separado)
cd frontend
npm install
npm run dev
```

## BANCO DE DADOS
Tabela `tasks`:
```sql
CREATE TABLE tasks (
  id INT AUTO_INCREMENT PRIMARY KEY,
  title VARCHAR(255) NOT NULL,
  status VARCHAR(50) DEFAULT 'pendente',
  created_at TIMESTAMP DEFAULT CURRENT_TIMESTAMP
);
```
