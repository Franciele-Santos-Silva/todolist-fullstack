# Documentação Detalhada do Projeto Lista React (App de Tarefas)

Este documento explica cada parte do código do projeto **lista-react-temp**, uma aplicação React para gerenciamento de tarefas. O app possui uma interface moderna com sidebar de navegação, lista de tarefas editável e painel de detalhes. Usa React 18+, Context API para estado global e hooks personalizados.

O projeto está estruturado em pastas: `src/components/`, `src/contexts/`, `src/hooks/`, `src/utils/`, com estilos globais em `styles.css`.

## 1. package.json
**Propósito**: Configuração do projeto React (Create React App).
- **Dependências principais**:
  - `react@^19.2.4`, `react-dom@^19.2.4`: Core do React.
  - `react-scripts@5.0.1`: Scripts para build, start, test.
  - Testing libraries (não usadas no app principal).
- **Scripts**:
  - `npm start`: Inicia servidor de desenvolvimento.
  - `npm build`: Gera build de produção.
- **Estrutura**: App privada (`private: true`), sem dependências externas complexas.

## 2. src/index.js (Ponto de Entrada)
**Propósito**: Renderiza a aplicação React no DOM.
```jsx
import React from 'react';
import ReactDOM from 'react-dom/client';
import App from './App';
import './styles.css';

const root = ReactDOM.createRoot(document.getElementById('root'));
root.render(
  <React.StrictMode>
    <App />
  </React.StrictMode>
);
```
- Cria root com `ReactDOM.createRoot` (React 18+).
- Importa `App.js` como componente raiz.
- Aplica `StrictMode` para detecção de problemas.
- Carrega `styles.css` global.
- Monta no `#root` (definido em `public/index.html`).

## 3. public/index.html
**Propósito**: Template HTML base (padrão CRA).
- Contém `<div id=\"root\"></div>` onde o app é montado.
- Meta tags, favicon, title \"React App\".

## 4. src/App.js (Componente Principal)
**Propósito**: Layout principal com provedor de contexto.
```jsx
import React from \"react\";
import { TaskProvider } from \"./contexts/TaskContext\";
import Sidebar from \"./components/Sidebar\";
import TaskList from \"./components/TaskList\";
import TaskDetail from \"./components/TaskDetail\";
import \"./styles.css\";

function App() {
  return (
    <TaskProvider>
      <div className=\"app-container\">
        <Sidebar />
        <TaskList />
        <TaskDetail />
      </div>
    </TaskProvider>
  );
}
export default App;
```
- Envolve tudo em `<TaskProvider>` (fornece estado global de tarefas).
- Container flex `.app-container`: Sidebar (esquerda), TaskList (meio), TaskDetail (direita).
- Importa CSS local.

## 5. src/contexts/TaskContext.js (Estado Global)
**Propósito**: Gerencia estado das tarefas com Context API + useState/useCallback.
```jsx
// ... imports
const TaskContext = createContext();
export const useTasks = () => useContext(TaskContext); // Hook customizado

const initialTarefas = []; // Array vazio (exemplos comentados)

export const TaskProvider = ({ children }) => {
  const [tarefas, setTarefas] = useState(initialTarefas);
  const [tarefaSelecionada, setTarefaSelecionada] = useState(null);

  // Funções memoizadas com useCallback
  const atualizarTarefa = useCallback((tarefaAtualizada) => { ... });
  const excluirTarefa = useCallback((id) => { ... });
  const adicionarTarefa = useCallback((titulo) => { ... }); // Cria nova tarefa com ID auto-incremental

  const value = { tarefas, tarefaSelecionada, setTarefaSelecionada, atualizarTarefa, excluirTarefa, adicionarTarefa };
  return <TaskContext.Provider value={value}>{children}</TaskContext.Provider>;
};
```
- **Estados**: `tarefas` (array de objetos {id, titulo, descricao, concluida, lista, dataVencimento, etiquetas, subtarefas}), `tarefaSelecionada`.
- **Funções**:
  - `adicionarTarefa(titulo)`: Nova tarefa com defaults.
  - `atualizarTarefa(tarefa)`: Merge por ID.
  - `excluirTarefa(id)`: Filtra e limpa seleção.
- Hook `useTasks()`: Acessa contexto (lança erro se fora do Provider).

## 12. src/styles.css (Estilos Globais)
**Propósito**: CSS completo (reset, layout flex, componentes).
- **Layout**: `.app-container` (flex 250px | 1.5 | 320px), scrolls custom.
- **Cores**: #7f7fff (primária), badges, dots (personal ff5c5c, work 1fa7ff).
- **Responsivo**: Overflow hidden/auto, hover effects, transições.

## Fluxo Geral da App
1. `index.js` → `App.js` (TaskProvider).
2. Layout: Sidebar | TaskList (add/lista) | TaskDetail (edit).
3. Estado global via Context: Adicionar/atualizar/excluir propaga em todos.
4. Seleção: Clique em TaskItem → abre Detail editável.
5. Sem persistência (estado reseta no refresh).

## Pontos Fortes/Melhorias
- Arquitetura limpa (Context + hooks).
- UI polida, acessível.
- **Melhorias**: LocalStorage, validações, roteamento real.

App rodando em `npm start`. Total ~1k LOC, foco em UX de lista de tarefas!
